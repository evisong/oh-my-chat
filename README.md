# `oh-my-chat` 样例应用

`oh-my-chat` (《我聊》) 是一款基于React技术开发的Web聊天应用。

本[`snapshots`](https://github.com/evisong/oh-my-chat/tree/snapshots)分支将各个章节的代码按目录平铺在一起，方便读者查看和学习。每个`ch*`开头的目录都包含了相应章节的代码，如`ch01_3_5`包含了1.3.5节的代码。请查看各个目录中的`README.md`文件以获取更多信息。

如果希望查看`oh-my-chat`代码演进的过程，请查看[`main`](https://github.com/evisong/oh-my-chat/tree/main)分支，及其[代码提交历史](https://github.com/evisong/oh-my-chat/commits/main)，或使用`git`命令检出`main`分支到本地进一步查看。

## 安装运行

```sh
npm install
cd ch01_3_5 # 进入对应章节目录
npm run dev
```
